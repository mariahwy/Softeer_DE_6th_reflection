## 1. Review
Docker Compose 파일을 이용하면 master/worker 노드를 한 번에 손쉽게 구성할 수 있다는 걸 알게 되었다.

이전에는 각각 컨테이너를 따로 띄우고 수동으로 설정했는데, 자동화된 방식이 존재했다는 점에서 큰 배움을 얻었다.

Hadoop 실행 시 root로 실행하는 것이 보안상 위험하다는 점을 인지했다.
→ 안전한 운영을 위해 별도의 hadoop 사용자 생성과 권한 설정이 필요함을 학습했다.

## 2. Keep (잘한 점)
오류 메시지를 읽고 구체적인 원인을 찾아보며 직접 수정해본 점

bash로 한 줄씩 테스트하며 Dockerfile 작업 내용을 안정적으로 검증한 점

Hadoop 구성 요소별 환경변수 설정의 중요성을 직접 실습을 통해 체감한 점

## 3. Problem (문제점)
Dockerfile로 사용자와 환경 설정을 했지만, hadoop 유저 전환 후 환경변수가 실제로 반영되지 않은 문제 발생

권한 부족으로 /usr/local/hadoop/... 경로에 디렉토리를 생성할 수 없었던 문제

JAVA_HOME 경로가 ARM64 환경에서 다르게 설정되어 Hadoop 실행 오류 발생 (/usr/lib/jvm/java-8-openjdk-arm64)

## 4. Try (구체적인 개선 방안)
사용자 권한과 디렉토리 소유권 변경은 Dockerfile에서 미리 설정해 이미지화하여 반복 실행 가능하게 만들어야겠다.

JAVA_HOME은 하드코딩하지 않고 readlink -f $(which java) 결과를 반영하도록 설정 스크립트를 수정하자.

.bashrc나 환경 파일을 설정했을 때는 반드시 source 재실행하거나 컨테이너를 재시작해 적용 여부를 검증하자.
