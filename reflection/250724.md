### 2. Keep : 
- hadoop 관련 용어와 개념에 익숙하지 않아서 헷갈렸다. master? worker? mapreduce? hdfs?
- 특히 docker에서 hadoop을 사용한 예제가 많이 없어서 더 헷갈렸던 것 같다.
- 노트에 docker부터, hadoop이 docker 위에서 어떻게 돌아가는지, master은 어떤 데몬, worker는 어떤 데몬을 실행해야하는지 그림을 그려보고, 이를 바탕으로 다시 공식문서로 학습하니 이해가 조금 더 잘 되었다.
- 앞으로도 이런 식으로 헷갈리는 개념은 뭉뚱그려 넘어가지 않고, 스스로 구상도를 그려보며 이해하도록 노력할 것이다.
