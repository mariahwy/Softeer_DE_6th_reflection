## 1. Review
어제 최종 제출일이라 밤을 새서 컨디션이 너무 안 좋았다. ㅠㅠ 그래도 얼마 남지 않았으니 발표까지 최선을 다해야겠다.
우리가 정의한 문제가 다른 사람들에게도 공감이 가는지 물어봤는데 여러 피드백을 구할 수 있어서 아이디어를 발전시킬 수 있었다.

## 2. Keep (잘한 점)
팀원들과의 팀워크나 분업은 잘 되고 있는 것 같다.

## 3. Problem (문제점)
모든 문제의 정답을 찾으려고 하는 점. 팀원들과 완벽한 정답을 찾으려고 하다보니 산으로 가는 것 같다. 휴리스틱하게 정답을 찾기보다는 빠르게 가설을 세우고 실제로 검증을 해보는 iteration 과정이 필요한데,
이번 프로젝트에서 방향성을 잘못 잡은 것 같다. 잘 진행되고 있다고 생각했는데 알고보니 그게 아니어서 발표가 얼마 남지 않은 시점에 막막했던 것 같다.

## 4. Try (구체적인 개선 방안)
앞으로 문제정의를 할 때 추상적인 문제가 아닌 구체적인 사례를 중심으로 먼저 생각할 것이다.
